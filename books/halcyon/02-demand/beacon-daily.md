# beacon-daily.csv

Beacon history by region: 56 days before day 1 for all regions, then each region while it remains on Beacon (East to day 36, West throughout). Beacon messaging is asynchronous with no timeout, so `messaging_elapsed_hours` is hours and only `messaging_aht_agent_sec` is comparable to Meridian chat **AHT (agent work)**. Definitions: **Transaction**, **Contact**, **Contacts per transaction**, **AHT (agent work)**.

## Provenance

Generated by `sim/generate.ts` (seed 20260720); synthetic data with a recorded ground truth in `sim/GROUND-TRUTH.md`. Regenerate with `bun run sim/generate.ts`. Rows: 325.
